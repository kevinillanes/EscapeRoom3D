# Escape Room 3D

Escape Room 3D es un juego en primera persona desarrollado en Unity 6 con
Universal Render Pipeline. El jugador explora una habitación cerrada, encuentra
cuatro pistas repartidas por el escenario, deduce un código numérico y lo
introduce para abrir un cofre medieval que contiene la llave de salida.

El proyecto es el soporte práctico de un laboratorio de control de versiones de
20 casos, donde cada integrante trabaja en su propia rama Feature y los
conflictos se provocan, documentan y resuelven de forma deliberada.

Proyecto colaborativo de laboratorio de Git + GitHub + Visual Studio Code + Unity.
